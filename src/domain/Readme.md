# Domain module.

Manage the persistance by saving on database with two JPA objects:

`StorageBlobEntity` represent the table on database.
`StorageBlobRepository` manage the entity with JPA.

## Instalation

```xml
<dependency>
  <groupId>com.thelastimperial.storage</groupId>
  <artifactId>domain</artifactId>
  <version>0.0.1</version>
</dependency>
```
