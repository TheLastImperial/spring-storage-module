# Web Module

The Web module expose a default controller to show the file by the UUID.

## Controllers

`StorageController` is used to response the object by the URL `/r/{id}`.

## Instalation

```xml
<dependency>
  <groupId>com.thelastimperial.storage</groupId>
  <artifactId>web</artifactId>
  <version>0.0.1</version>
</dependency>
```
